# Course Projects

Repositorio donde almaceno los proyectos y ejercicios que desarrollo mientras aprendo desarrollo Full Stack.

## 📚 Tecnologías

Dependiendo del proyecto, utilizo tecnologías como:

- Node.js
- Express
- TypeScript
- EJS
- Tailwind CSS
- Git
- GitHub

## 📁 Estructura

```
courseprojects/
│
├── fullstack/
│   ├── src/
│   ├── package.json
│   └── ...
```

## 🚀 Cómo ejecutar un proyecto

Instalar dependencias:

```bash
npm install
```

Ejecutar el servidor:

```bash
npm run dev
```

Compilar Tailwind CSS:

```bash
npm run dev:css
```

Este repositorio documenta mi proceso de aprendizaje en desarrollo Full Stack, incluyendo ejercicios, prácticas y proyectos realizados durante diferentes cursos.
